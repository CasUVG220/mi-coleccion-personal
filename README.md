# Mi Colección Personal — Entrenamiento Físico 

App full-stack para registrar sesiones de entrenamiento.

## Stack
- Frontend: React 18 + Vite
- Backend: Node.js + Express + SQLite
- Estado: useState, useEffect (Fase 1)

## Cómo correr el proyecto

### Frontend
cd frontend
npm install
npm run dev

### Backend
cd backend
npm install
node src/index.js
